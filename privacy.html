Privacy Policy

Last updated: October 20, 2026

Overview

YouTube Channel 10 Uploader is a private, personal automation application created solely to manage and upload video content to the owner's personal YouTube channel (Mazhar Iqbal) and read video files from the owner's personal Google Drive folder.

Google API Usage & Data Handling

The application connects directly to the Google Drive API and YouTube Data API exclusively to transfer the user's video files from Google Drive to YouTube.

No user data, personal information, or media files are ever transferred, sold, shared, or stored on external servers or with any third parties.

Data Retention

Authentication credentials and tokens are retained securely and solely within the application owner's isolated environment. No third-party data is retained or stored.

Revocation of Access

You can revoke access to this application at any time via Google Account Security Settings: https://myaccount.google.com/permissions.
